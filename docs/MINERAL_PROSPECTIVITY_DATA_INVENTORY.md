## Findings that affect implementation

1. **The best starting point is the published local benchmark, not a brand-new global satellite scrape.** The 2024 study already has local target labels and compiled covariates, and its methods allow a direct reproduction/partial-reproduction question. The publisher lists the supplementary package as a single ~142,100 KB PDF; inspecting/extracting its content is now an explicit first task, not an assumed completed step.
2. **A public Africa-wide geodatabase can unblock the first ingestion test.** USGS's 2021 Africa mineral-industries release is public and marked CC0 1.0, with mineral occurrence/deposit, exploration, infrastructure and selected undiscovered-tract layers. Use it to exercise data manifests and spatial joins first, but not as a substitute for South Africa's benchmark covariates or independent ground truth.
3. **CGS provides a practical data route and an independent prior-work check.** Its catalogue lists no-cost 1:1,000,000 geology vector data but portal downloads require an account; this particular package was not retrieved here. CGS also lists selected simplified mineral/geology maps for public use, and describes earlier prospectivity work for fluorite and tin–tungsten. Verify underlying asset terms and obtain the actual model/data before comparing outputs.
4. **Remote sensing is a later ablation, not a prerequisite.** Test its added value over geology/geophysics baselines with identical spatial folds and a valid-data mask.
5. **USGS data outside the Africa-specific release are not South African substitutes.** Use them for relevant global comparisons or method tests unless an individual dataset is genuinely appropriate to the target area.
6. **Deep-time reconstruction is deferred.** It should enter only if a defined mineral-system hypothesis can be supported by a compatible reconstruction model and data.
7. **The first reproducible expansion beyond PGE can be guided by CGS's own knowledge-gap program.** After the PGE reproduction, investigate whether lawful source layers and comparable reference labels exist for Sn–W, Cu–Pb–Zn or Ti–V; begin by comparing to documented CGS work, not by assuming these targets are undiscovered.
8. **Spatial support differs across input layers.** The paper uses H3 resolution 7 (average cell area ~5.16 km²; edge ~1.22 km), but reports regional Bouguer gravity station spacing around 14 km. H3 aggregation makes a common index; it does not improve the underlying measurement resolution. Preserve source support and quality masks per layer.
9. **No source files have been downloaded, verified, or added to this repository by this inventory.** This status must not be confused with a completed data pipeline.

## Executable preflight available

A read-only Python standard-library tool now exists at [scripts/mineral-prospectivity/inspect_bundle.py](../scripts/mineral-prospectivity/inspect_bundle.py), with usage notes in its README and synthetic safety tests in [tests/test_inspect_bundle.py](../tests/test_inspect_bundle.py). It hashes the original file and inspects ZIP central-directory paths, extensions, size/compression indicators, and probable Shapefile sidecars without extracting content. It does not establish archive payload integrity, parse CRS/geometry/attributes, or establish rights. The source geodatabase has not yet been run through this tool because this environment cannot directly fetch the source archive.

## M0 completion checklist

- [ ] USGS Africa geodatabase layers inventoried and used for a metadata/spatial-join smoke test, with source ancestry preserved.
- [ ] Supplementary PDF inspected for embedded datasets/artifact links; artifacts listed with names, digests, extraction method, and per-asset terms.
- [ ] The official 1:1,000,000 geology vector package and selected public-use map products have their exact artifact IDs, vintage, access method and reuse terms recorded.
- [ ] Any existing CGS Bushveld prospectivity outputs used for comparison have their study area, inputs, model/version and permissions documented.
- [ ] Every candidate layer has a completed manifest conforming to [the dataset manifest schema](schemas/mineral-dataset-manifest.schema.json).
- [ ] Missing coverage, invalid/no-data regions, units and coordinate reference systems are documented.
- [ ] A reviewer checks the provenance and reuse decision before data ingestion.
- [ ] No restricted dataset content is committed or published inadvertently.
