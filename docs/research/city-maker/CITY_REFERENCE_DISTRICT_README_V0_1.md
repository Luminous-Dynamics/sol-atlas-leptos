# CityMaker reference district profile v0.1

This machine-readable file is a parameterized template for the first synthetic above-ground district integration demonstrator. It intentionally leaves population, household counts, service demand, site, climate, cost and operating profiles null or Unknown until a rights-cleared source or a clearly labelled synthetic test parameter is declared.

The template instantiates a small number of asset archetypes (dwelling, clinic, education, food market, maintenance/recovery) and lists the evidence owner for each part of the buildability/service chain. It does not create new owners for supply, physical flows, capability closure, routing, service access, or commissioning.

The next step is to fill a synthetic test instance with bounded fixtures, preserve the parameterized template as immutable input, and run the composed owner adapters under the CityMaker reference-district corpus. No values in this template are claims about Johannesburg or any specific population, site, supplier or facility.
