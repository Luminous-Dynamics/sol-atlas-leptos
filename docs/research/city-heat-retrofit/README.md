# City heat retrofit atlas v0.1

This folder defines evidence admission for a prospective Johannesburg heat-risk and retrofit opportunity atlas.

- `CITY_HEAT_RETROFIT_EVIDENCE_PROFILE_V0_1.md` defines data classes, claim levels, spatial/temporal joins, thermal model and measurement receipts, matched intervention protocol, metrics and claim limits.
- `CITY_HEAT_RETROFIT_EVIDENCE_PROFILE_V0_1.json` is the machine-readable profile.

No Johannesburg heat layer, indoor thermal trajectory, sensor dataset or retrofit effect has been ingested or qualified by these files. Start with rights and metadata. Use City of Johannesburg MetroView only after per-layer access and licence checks. Use TMYx for energy screening, not a heatwave claim. Use ward-level population estimates only at ward resolution. Consume qualified building-model outputs from Symtropy #1848/#1900 and actual physical flow evidence from Mycelix Living-City; do not create parallel solvers or ledgers.

Primary parent: [Sol-Atlas #593](https://github.com/Luminous-Dynamics/sol-atlas-leptos/issues/593).
